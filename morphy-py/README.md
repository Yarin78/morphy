# morphy-py

A Python reader for the **v2** ChessBase format — the `.2cbh` family that
ChessBase 17 introduced. It is what the specification in
[../format/v2](../format/v2) was written from, and it stays in step
with it: if the two disagree, one of them is wrong.

It does not read the v1 `.cbh` format. The Java library in
[../morphy-cbh](../morphy-cbh) does that.

## Running it

Nothing to build, and no dependency beyond `click`:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python inspect --help
```

`inspect` reads a database, given the path to its `.2cbh` file (the extension
may be left off):

```bash
.venv/bin/python inspect games      ../test-databases/wch2/wch2
.venv/bin/python inspect moves      ../test-databases/wch2/wch2 --game-id 1
.venv/bin/python inspect annotations ../test-databases/wch2/wch2
.venv/bin/python inspect players    ../test-databases/wch2/wch2
.venv/bin/python inspect sorted     ../test-databases/wch2/wch2 "Default Spieler"
```

`hexit` dumps records as annotated hex, for looking at bytes the readers do not
decode yet.

## Layout

| | |
|---|---|
| `cb2/` | the package: one module per file of the format, plus the shared encodings |
| `inspect` | print games, moves, annotations, entities and indexes |
| `hexit` | annotated hex dumps |

Each module names the specification file it implements in its docstring. The
figures in the specification are generated by `../format/v2/img/make.py`.

## Sample databases

`../test-databases/wch2/` holds the World Championship database converted to v2,
the twin of the v1 copy in `morphy-cbh/src/test/resources`. The hand-made probe
databases used while working out the format are not in the repository; see
`../test-databases/scratch/sync.sh`.
